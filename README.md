Recreation of the uploaded 50.6-second screen recording titled **CSS Button Animation**.

## Effects in the video (in order)

1. Neon Cyberpunk
2. Liquid Wave Fill
3. Diagonal Swipe
4. Border Draw
5. Cyber Glitch
6. 3D Cube Flip
7. RGB Conic Glow
8. Holographic Foil
9. Diagonal Clip Split
10. Glassmorphism Orb

Each example is interactive: hover (or tap on touch devices) over its button to preview the effect. The page follows the recording's black canvas, blue-glow heading, orange frame, dark dotted preview stage, cyan effect labels and right/below code panels.

## Run

1. Extract the ZIP.
2. Open `index.html` in a modern browser.
3. Hover each button to test its CSS animation.

No JavaScript, dependencies, package installation, external fonts, or build step required.

## Files

- `index.html` — all ten demos and visible HTML/CSS sample panels
- `style.css` — responsive gallery, button styles, transitions and keyframes
- `README.md` — project guide

## Source accuracy

The effect names and visual behavior are based on the supplied screen recording. The small code panels in the recording are low-resolution and only partly legible. The snippets shown in this project are clean, working implementations of each demonstrated effect, not a verbatim transcription of every hidden original declaration. The full runnable page is reconstructed from the visible UI and behavior.
